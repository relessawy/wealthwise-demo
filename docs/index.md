# WealthWise developer guide

WealthWise is the ACME Bank training application. Its financial and investment
conversations are scripted demonstrations. Use synthetic data only.

## Explore the application

- **Financial Advisor** and **Investment Recommendations** demonstrate authenticated conversations.
- **History** shows the signed-in user's saved conversations.
- **Savings goal** calculates a monthly contribution and displays the API's guidance.

The [savings API](savings-api.md) and [WW-1 exercise](developer-journey.md)
connect the application to its API contract, tests and documentation.

Documentation is built from the same source revision as the application delivery.
The publishing pipeline must record that revision; an old Docs page is not evidence
of a newly deployed change.
